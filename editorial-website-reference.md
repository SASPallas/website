# Editorial Website Reference

## Creative Direction

Design a high-end editorial-style website inspired by contemporary European publishing houses, literary agencies, independent cultural publishers, and modern art institution websites.

The website should feel:

- culturally sophisticated
- intellectual
- minimal
- cinematic
- timeless
- calm
- curated
- refined

The design should avoid the feeling of a generic startup website. It should not look like SaaS marketing, Webflow templates, venture-backed product pages, dashboard UI, or conversion-first landing pages.

The strongest reference mood is:

**a contemporary Paris literary institution meets an art-house publishing agency and luxury editorial archive.**

## Visual References

Use the atmosphere of:

- independent European publishing agencies
- literary gallery websites
- modern art institution websites
- luxury editorial portfolios
- cultural foundation websites
- art catalogue and archive layouts
- intellectual culture magazines

The site should feel more like a cultural object than a software brochure.

## Design Principles

### Editorial Sophistication

The visual system should be led by typography, rhythm, negative space, and image composition.

Prioritize:

- asymmetrical editorial grid layouts
- oversized margins
- refined whitespace
- strong image rhythm
- museum-quality presentation
- quiet confidence
- intellectual restraint

Avoid:

- cards as the main layout device
- gradients
- glassmorphism
- bright accents
- startup blue
- dense SaaS sections
- heavy icons
- over-explained feature blocks

### Understated Luxury

The tone should feel expensive without appearing decorative.

Use restraint:

- fewer elements
- better spacing
- deliberate type scale
- carefully cropped imagery
- subtle interaction details
- muted archival colors

Luxury should come from proportion, silence, materiality, and editorial judgment rather than ornament.

## Layout System

Use a modular editorial grid inspired by Swiss modernism and luxury print magazines.

Recommended structure:

- maximum content width: `1400px` to `1600px`
- generous horizontal margins
- large vertical spacing between sections
- section separation through whitespace, not borders
- occasional full-bleed image sections
- alternating text and image compositions
- staggered editorial grids
- asymmetrical layouts with intentional imbalance

The page should breathe. Vertical rhythm should feel airy and calm.

Do not build the site from boxed dashboard components. Avoid nested panels, heavy containers, and card-based section design.

## Typography

Typography is the primary visual identity.

### Heading Type

Use an elegant serif for major headings.

Reference families:

- Canela
- Editorial New
- Cormorant Garamond
- Domaine

Heading style:

- large editorial scale
- thin or light weights
- generous line height
- refined proportions
- minimal punctuation where possible

### Body And Navigation Type

Use a neutral grotesk sans for body copy, navigation, labels, and utility text.

Reference families:

- Neue Haas Grotesk
- Suisse Intl
- Inter
- Helvetica Neue

Body and navigation style:

- lowercase navigation
- light to regular weights
- generous spacing
- calm paragraph measure
- occasional uppercase tracking for labels
- no heavy UI hierarchy

Avoid bold, loud, product-marketing typography.

## Color Palette

The palette should feel literary, Parisian, archival, and quiet.

Base colors:

- warm white: `#F7F5F1`
- bone
- soft cream
- charcoal
- muted taupe
- deep gray-black

Accent colors should be rare and restrained:

- muted burgundy
- dark olive
- faded navy

Avoid:

- bright colors
- saturated gradients
- neon
- startup blues
- high-chroma accent systems

Color should support the editorial atmosphere rather than compete with it.

## Imagery

Imagery should feel connected to:

- independent publishing
- literary journals
- art catalogues
- gallery archives
- book covers
- editorial still life
- intellectual culture magazines

Use:

- large photography blocks
- monochromatic or muted imagery
- book covers treated as artwork
- strong crop composition
- image-forward layouts
- asymmetrical visual balance

Image crops may be aggressive and artistic. Images should carry rhythm, not merely illustrate content.

Intermittently include full-bleed image moments to create cinematic pacing.

## Interaction Design

Motion should be extremely restrained and elegant.

Use:

- soft fade-ins
- slow image scaling on hover
- subtle underline animations
- smooth scrolling
- cinematic page or section transitions

Avoid:

- bouncing animations
- flashy hover effects
- excessive motion
- parallax overload
- interaction patterns that feel playful or tech-forward

The interaction model should feel quiet and intentional.

## Component Style

### Navigation

Navigation should be minimal and typographic.

Use:

- thin type
- generous spacing
- lowercase labels
- subtle hover states
- understated active states

Avoid bulky navigation bars, heavy buttons, and loud CTAs.

### Buttons And Links

Buttons should feel text-first.

Use:

- understated borders
- minimal fills
- refined spacing
- subtle underline or reveal animations
- quiet microinteractions

Avoid large rounded SaaS buttons, bright filled CTAs, and aggressive conversion styling.

### Sections

Sections should feel like editorial spreads.

Use:

- alternating layouts
- text and image interplay
- staggered grids
- wide margins
- strong typographic hierarchy
- negative space as a design material

Avoid boxed dashboard components and repeated card rows.

## Overall Mood

The final result should feel like:

- a contemporary Paris literary institution
- an art-house publishing agency
- an intellectual cultural foundation
- a luxury editorial archive

The user experience should feel calm, intelligent, curated, refined, and deeply intentional.

## Implementation Guardrails

Before considering the design successful, check that:

- the site does not read as a generic startup landing page
- typography carries the visual identity
- whitespace is generous enough to feel editorial
- imagery is large, cropped, and rhythmically composed
- sections are separated by space rather than boxed containers
- motion is quiet and restrained
- accent colors are rare
- navigation is minimal and typographic
- the design favors editorial elegance over conversion optimization

The core instruction is:

**Prioritize editorial elegance, cultural confidence, and visual restraint over startup-style clarity, feature density, or conversion pressure.**
